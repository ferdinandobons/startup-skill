# 核验清单

> 本文供技能按需读取。默认面向中国大陆市场、使用简体中文；若目标含港澳台或海外，须单独说明制度与数据差异。

## 核验任务

独立复查全部交付物：

- 数字是否有来源、日期、地域、单位和统一口径；
- 事实、推断、假设是否清楚标注；
- 是否存在自相矛盾、过期价格、重复来源假佐证；
- 是否遗漏中国的数据、广告、行业许可、税务或平台规则风险；
- 建议是否与证据一致，战卡/定位/路演之间是否冲突；
- 是否泄露个人信息或使用无法证明的绝对化表达。

输出 `verification-report.md`，按严重/重要/建议分级，列出文件位置、问题、修正方式。严重问题必须暂停并请求用户决定；不得自行把问题标为已解决。
